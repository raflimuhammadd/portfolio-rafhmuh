## Overview
A fully responsive restaurant landing page for Dapoer Bunda built with vanilla HTML, CSS, and JavaScript. Features a modern design with dark/light theme toggle, smooth scroll animations, and mobile-optimized navigation for showcasing restaurant services, menu items, and contact information.

## The Challenge
- Create an engaging, responsive landing page that works seamlessly across all devices
- The site needed to showcase restaurant offerings (services, menu) and provide contact options without relying on frameworks.

## Key Features
- Dark/Light Theme Toggle. Persistent theme preference using localStorage
- Scroll-to-Top Button. Fixed button that appears after scrolling 560px
Menu Showcase: Product grid with add-to-cart buttons
- App Download Section. Links to mobile app stores

## The Solution
- LocalStorage. Persisting user's theme preference across sessions
- ScrollReveal Integration. Staggered animations on page scroll for visual interest

## Outcomes & Impact
- Fast loading. No framework overhead, pure HTML/CSS/JS
- Mobile-optimized. Tested across multiple screen sizes
- User experience focused. Dark mode support, smooth transitions, intuitive navigation
- Fully accessible: Semantic HTML with proper navigation structure

## Lessons Learned
- Vanilla JavaScript is sufficient for interactive landing pages without framework complexity
-  LocalStorage is a simple way to persist user preferences without backend dependencies
- Scroll-based animations enhance UX but should be used purposefully to avoid distraction
