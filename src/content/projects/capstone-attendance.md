# Capstone Project: Smart Attendance System

## Overview
University capstone project: Face recognition attendance system untuk university lectures dengan mobile app dan admin dashboard.

## The Challenge
Mengembangkan system yang dapat automatically track student attendance menggunakan face recognition, mengurangi manual work, dan provide insights ke faculty.

## Key Features
- **Face Recognition**: Real-time face detection dan recognition
- **Mobile App**: React Native app untuk students check-in
- **Web Dashboard**: Admin dashboard untuk faculty management
- **Real-time Tracking**: Live attendance tracking selama lectures
- **Analytics**: Attendance patterns dan insights

## The Solution
- **React Native**: Cross-platform mobile app untuk iOS dan Android
- **Express.js**: REST API untuk mobile app dan web dashboard
- **Face Recognition**: Python service dengan OpenCV dan deep learning
- **WebRTC**: Real-time video streaming untuk face capture
- **PostgreSQL**: Relational database untuk student data dan attendance

## Outcomes & Impact
- Reduced attendance taking time dari 15 minutes ke 2 minutes
- 98% accuracy pada face recognition
- 95% adoption rate di pilot class
- Valuable insights tentang student engagement patterns
- Scalable architecture untuk university-wide deployment

## Lessons Learned
- Privacy considerations sangat important untuk face recognition systems
- Proper error handling critical untuk production systems
- User testing provides valuable feedback untuk improvement
- Academic projects perlu balance antara innovation dan practicality
